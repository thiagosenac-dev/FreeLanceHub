# FreeLanceHub

Plataforma de freelance que conecta pessoas em busca de projetos ou pessoas em busca de oportunidades, tudo dentro do mesmo sistema. Permitindo criar projetos ou dar propostas em cima de projetos terceiros... A ideia é facilitar para pessoas/empresas que buscam alguém temporário para realizar um serviço, e também ajudar aquele que busca apenas um Job temporário.
